# 📚 文具店微信小店小程序内嵌项目 (xiaodian)

本项目完全基于微信官方最新的 **「小程序连接微信小店」** 原生能力开发。
无需自建后端服务器和数据库，全套商品交易、微信支付、快递打单物流与售后退换均由**腾讯微信小店官方**全权提供。

---

## 📌 当前已配置参数

- **小程序 AppID**: `YOUR_MINI_APP_ID`
- **微信小店 AppID**: `YOUR_SHOP_APP_ID`
- **默认文具商品 ID**: `10001670576194`
- **基础库版本要求**: `>= 3.7.2`

---

## 🚀 如何在微信开发者工具中预览与调试？

1. 打开 **微信开发者工具**。
2. 点击 **【导入项目】**，目录选择：
   `d:\Claude code\wenju-shop\xiaodian`
3. AppID 填入您的小程序 AppID。
4. 在开发者工具右上角 **【详情】 -> 【本地设置】**：
   - 检查 **调试基础库**，请确保选择 **`3.7.2` 或更高版本**（必须 >= 3.7.1 才能支持 `<store-product>` 与 `<store-home>` 组件）。
5. 此时即可在模拟器中看到：
   - 首页：微信小店官方整店嵌入组件展示 (`<store-home>`)。
   - 精选文具页：您的文具商品卡片展示 (`<store-product>`)，点击“购买”直接在小程序底部半屏拉出官方结算收银台！
   - 我的订单页：快捷查看小店订单、发货物流与售后通道。

---

## 🔗 微信小店后台“账号关联”操作指引 (重要)

根据官方文档规范，为了确保组件正常展示并开通更多权限，建议在小店后台做一次关联：

1. 电脑浏览器登录 [微信小店商家后台](https://store.weixin.qq.com/)。
2. 进入 **【店铺管理】 -> 【账号管理】 -> 【小程序】**。
3. 点击 **【去关联】** / **【新增关联小程序】**。
4. 输入您的小程序 AppID 并按提示完成管理员扫码授权确认即可。

---

## ➕ 如何在小程序中增加更多文具商品？

在微信小店后台发布新的文具商品后，只需打开 `xiaodian/config.js` 文件，在 `featuredProducts` 数组中添加新的商品 ID 即可：

```javascript
featuredProducts: [
  {
    productId: '10001670576194',
    title: '精选热销文具',
    tag: '爆款推荐'
  },
  {
    productId: '您新上架的商品ID',
    title: '商品名称',
    tag: '新品上市'
  }
]
```
页面将自动多渲染出一个支持半屏下单的微信小店商品卡片！
